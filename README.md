# Web_Bai_Tap_TA_CaoThang

Web luyện thi trắc nghiệm (HTML/CSS/JS thuần, giao diện neo-brutalism).

- Đề ngẫu nhiên 50 câu, 45 phút, đáp án xáo mỗi lần làm, không lặp câu cũ.
- Soạn bộ đề: chia toàn bộ câu hỏi thành n đề không trùng, không sót.
- Xem lại đáp án, lịch sử lưu trong localStorage, nút Reset.

Mở `index.html` hoặc deploy như một trang tĩnh (GitHub Pages, Netlify, Vercel...).

Dữ liệu câu hỏi nằm trong `questions.js`, sinh từ các file xlsx bằng `python tools/build_questions.py`.
